# HACKSPIRE: LUMINA — Database Schema
### 🆕 = added/changed from the latest dev-team meeting and Excel review. Auth is now **Supabase Auth** — sign-in, password reset, email-change verification, and invites all go through GoTrue; the app no longer mints its own JWTs. Sponsors and contact info are hardcoded in the Flutter frontend — no DB tables for either.

## profiles
Extends Supabase's built-in `auth.users` — one row per login account, participant or admin.

| Column | Type | Notes |
|---|---|---|
| id | uuid | PK, matches `auth.users.id` (invite flow guarantees this; legacy rows may mismatch and are linked by email) |
| name | text | |
| email | text | unique — mirror of the confirmed auth.users email, synced lazily after an email change is verified |
| student_staff_id | text | unique — used for dedup on Excel import |
| role | text | `participant` \| `admin` |
| first_login | boolean | only set by admin password resets now (forces a change on next login); obsolete for invited accounts |
| **invite_status** | text | 🆕 `invited` (invite email sent, not yet accepted) \| `active` (password set / logged in) \| `failed` (reserved for SMTP bounce webhooks) |
| **username** | text | 🆕 unique, editable by the user |
| **reference_id** | text | 🆕 unique — comes pre-filled from the Excel import, not generated by the system |
| **university_name** | text | 🆕 nullable, free text — from Excel import or self-edited via profile |
| **technical_skills** | text | 🆕 nullable, free text or comma-separated tags |
| **preferred_role** | text | 🆕 nullable, e.g. "Frontend", "Design", "Pitching" |
| created_at | timestamptz | |

## submissions
🆕 3 link fields — GitHub, infographic, and pitch deck are now separate links. Open to any team member, not leader-only. 🆕 Two rounds: round 1 (qualifying, all approved teams) and round 2 (finalist judging, published finalists only) — a team may have up to one row per round.

| Column | Type | Notes |
|---|---|---|
| id | uuid | PK |
| team_id | uuid | FK → teams.id, ON DELETE CASCADE — unique together with `round` |
| **round** | smallint | 🆕 `1` (qualifying) or `2` (finalist) |
| **github_url** | text | 🆕 nullable |
| **infographic_url** | text | 🆕 nullable — link to the team's infographic |
| **pitch_deck_url** | text | 🆕 nullable — link to the team's pitch deck |
| **submitted_by** | uuid | 🆕 FK → profiles.id — tracks which team member last submitted/edited |
| submitted_at | timestamptz | |
| updated_at | timestamptz | set whenever the submission is edited |

## Relationships Summary
- profiles 1—N teams (as leader)
- teams 1—N team_members N—1 profiles — cascades on team delete
- teams 1—N join_requests N—1 profiles — cascades on team delete
- teams 1—N submissions (one per round, max 2) — cascades on team delete
- profiles 1—N submissions (as submitted_by)
- teams 1—1 finalists (optional)
- teams 1—1 winners (optional)
- profiles 1—N materials (as uploader)
- profiles 1—N announcements (as poster)
- profiles 1—N audit_log (as admin actor)
- profiles 1—N notifications (as recipient)
